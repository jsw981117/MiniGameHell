# Star Dodge - Mini Game Hell

HTML5 Canvas로 구현한 2D 아케이드 서바이벌 게임

## 🎮 게임 소개

**Star Dodge**는 떨어지는 메테오를 피하면서 별을 수집하는 간단하지만 중독성 있는 게임입니다.

### 주요 특징
- 자동 이동하는 플레이어 (2단 점프 가능)
- 점점 빨라지는 난이도
- 실시간 설정 조정 기능
- PC/모바일 크로스 플랫폼 지원
- 반응형 디자인

## 📂 프로젝트 구조


## 🚀 실행 방법

### 방법 1: 브라우저에서 직접 실행
1. `index.html` 파일을 더블클릭
2. 브라우저에서 자동 실행

### 방법 2: 로컬 서버 사용 (권장)
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server

# 브라우저에서 http://localhost:8000 접속
```

## 🎮 게임 방법

### 조작법
- **PC**: 스페이스바 또는 마우스 클릭으로 점프
- **모바일**: 화면 터치로 점프

### 게임 규칙
1. 플레이어는 자동으로 좌우로 이동합니다
2. 노란색 별을 수집하면 점수가 올라갑니다
3. 빨간색 메테오에 닿으면 게임 오버!
4. 최대 2번까지 연속 점프 가능합니다
5. 시간이 지날수록 메테오가 더 빨리 떨어집니다

### 컨트롤 버튼
- **게임 시작**: 게임을 시작합니다
- **일시정지**: 게임을 일시정지합니다
- **재시작**: 게임을 처음부터 다시 시작합니다
- **⚙️ 설정**: 게임 밸런스를 조정합니다

## ⚙️ 설정

우측 상단 ⚙️ 버튼을 클릭하여 다음 항목을 조정할 수 있습니다:

### 플레이어 설정
- 이동 속도
- 점프력
- 중력

### 메테오 설정
- 최소/최대 속도
- 초기 생성 주기
- 최소 생성 주기
- 난이도 증가율

## 🛠️ 기술 스택

- **HTML5 Canvas**: 게임 렌더링
- **Vanilla JavaScript**: 게임 로직 (프레임워크 미사용)
- **CSS3**: UI 디자인 및 애니메이션
- **객체 풀링**: 성능 최적화
- **AABB 충돌 감지**: 효율적인 충돌 처리

## 📊 성능 최적화

- 객체 풀링 패턴으로 메테오 재사용
- AABB 충돌 감지 알고리즘
- 반응형 캔버스 스케일링
- Debounce를 활용한 이벤트 최적화
- deltaTime 기반 프레임 독립적 움직임
